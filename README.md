# 금자의 자기소개 포트폴리오

React + JavaScript + Vite 실습 템플릿을 바탕으로 만든 금자의 자기소개 사이트입니다.
핫핑크와 민트를 사용하며, 첫 인삿말은 “어서 와, 금자는 처음이지?”입니다.
게임과 잠자기, 잘하는 것과 배우고 싶은 것, 앞으로의 목표를 소개합니다.
자기소개 메뉴·버튼은 별도의 자기소개 페이지(`#/about`)로, 포트폴리오 메뉴·버튼은 포트폴리오 목록 페이지(`#/portfolio`)로 이동합니다.
각 페이지에서 홈으로 돌아가기와 브라우저 뒤로 가기·새로고침을 사용할 수 있습니다.
프로젝트 정보는 `src/App.jsx`의 `projects`에서 관리합니다. 목록 카드에서 상세 소개와 GitHub 링크를 확인할 수 있습니다.
자기소개 사이트, 마라탕 취향 조합기, 음식 취향 월드컵을 작품으로 소개합니다.
게임 작품의 상세 화면에는 실제 게임으로 이동하는 ‘직접 해보기’ 버튼이 있습니다.
작품은 `number`, `category`, `title`, `description`, `style`, `overview`, `goal`, `process`(배열), `learning` 항목을 사용합니다. 선택 항목인 `githubUrl`이 있으면 상세 화면에 GitHub 링크를 표시합니다.
선택 항목 `role`은 맡은 역할, `playUrl`은 게임 이동 링크, `artwork`는 기본 그림 대신 사용할 장식용 이모지입니다. `learning`이 비어 있으면 배운 점 섹션을 생략합니다.
`style`은 작품 주소와 CSS 그림에 함께 쓰입니다. 기존 그림은 `website`, `idea`, `creative`를 지원합니다.
카드를 누르면 `#/portfolio/<style>` 주소의 상세 화면이 열립니다.
사진은 나중에 `public/`에 추가할 수 있으며, 사진이 없어도 기본 그림을 사용합니다.

## 마라탕 취향 조합기

홈의 시작 버튼이나 메뉴에서 `#/mala`로 이동합니다.
30가지 재료를 개수 제한 없이 선택하고 금자의 14가지 재료와 비교합니다.
일치율은 함께 고른 재료 수를 둘 중 한 명이라도 고른 재료 수로 나눈 뒤 반올림한 백분율입니다.
결과에서 재료를 바꾸거나 처음부터 다시 할 수 있습니다. 선택은 서버에 저장하지 않으며 화면을 나가거나 새로고침하면 초기화됩니다.
화면은 `src/MalaGame.jsx`, 스타일은 `src/MalaGame.css`, 재료와 비교 계산은 `src/mala.js`에서 관리합니다.
계산 확인: `node --test src/mala.test.js` (특정 항목만 실행: `node --test --test-name-pattern="partial overlap" src/mala.test.js`).

## 음식 취향 월드컵

홈이나 메뉴에서 `#/food-worldcup`으로 이동합니다. 식사 16가지와 간식 16가지를 섞어
32강 → 16강 → 8강 → 4강 → 결승으로 진행하며, 31번 선택하면 우승 음식이 정해집니다.
대진은 시작할 때마다 무작위이며 선택 기록, 이전 선택으로 돌아가기, 다시 하기 기능이 있습니다.
이전 선택으로 돌아가면 라운드가 바뀐 직후나 결승 결과도 수정할 수 있습니다.
진행 중인 판은 페이지 이동·새로고침 시 초기화됩니다.
완료 후 ‘결과 저장하기’를 누르면 31경기의 선택을 이 브라우저의 `localStorage`에 누적합니다.
순위는 우승 횟수가 아닌 매 경기 선택 횟수 기준이며, 동점은 공동 순위입니다.
같은 판은 한 번만 저장되고 저장 후 뒤로 돌아가면 해당 판의 기록도 취소됩니다.
다른 기기·브라우저 결과와 공유되지 않으며 브라우저 데이터를 지우면 누적 기록도 삭제됩니다.
저장소 접근 실패나 손상은 화면에 안내하고 기존 데이터를 덮어쓰지 않습니다.
화면과 스타일은 `src/FoodWorldCup.jsx`, `src/FoodWorldCup.css`,
후보·대진 로직은 `src/foodWorldCup.js`에서 관리합니다.
기록·순위는 `src/foodRankings.js`에서 관리합니다.
테스트: `node --test src/foodWorldCup.test.js src/foodRankings.test.js`.

## 내 프로젝트로 시작하기

1. GitHub의 **Use this template → Create a new repository**로 자신의 저장소를 만듭니다.
2. 새로 만든 저장소를 컴퓨터로 복제하고 Visual Studio Code에서 엽니다.
3. 아래 실행 방법에 따라 사이트를 실행합니다.
4. GitHub Copilot과 함께 자기소개, 프로젝트 설명, 색상과 이미지를 자신의 내용으로 바꿉니다.

소개에는 본인이 알려 준 내용만 사용하고, 연락처·주소·생년월일은 넣지 않습니다.

## 실행하기

1. Node.js 24 LTS를 설치합니다.
2. Visual Studio Code에서 복제한 프로젝트 폴더를 엽니다.
3. 터미널에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 수정할 파일

- `src/App.jsx`: 화면 내용과 React 컴포넌트
- `src/App.css`: 화면 스타일
- `src/index.css`: 전체 공통 스타일
- `public/`: 직접 사용할 이미지 등 정적 파일

파일을 수정하고 저장하면 실행 중인 브라우저에 반영됩니다.

## 확인 명령

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다.
